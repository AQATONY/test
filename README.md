## Основная позиция QA

ЭТрН здесь нельзя тестировать как обычную форму. Риск не только в UI-валидации, а в корректной связке:

- ролей участников перевозки;
- последовательности титулов;
- статусов документа;
- электронной подписи;
- XSD-валидности обменных файлов;
- обработки замечаний при погрузке и выгрузке;
- интеграции с оператором ЭДО и ГИС ЭПД.

Поэтому я разделил проверки на процессные, формальные XSD-проверки, негативные сценарии и интеграционные риски.
