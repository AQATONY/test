# Блок 2. AI Prompting & Review

## Состав блока

- `prompt.md` - prompt, который был бы отправлен в LLM.
- `raw_ai_response.md` - сырой ответ ИИ без редакторской правки.
- `review.md` - мое ревью ответа: что полезно, что пропущено, что удалить.
- `boundary_conditions.md` - финальные граничные условия и пояснение критичности.

## Подход

Я использовал ИИ не как источник истины, а как генератор первичного списка проверок. Дальше список отфильтрован с позиции QA для логистической формы:

- проверены реальные бизнес-риски расчета перевозки;
- добавлены интеграционные сценарии POST-запроса;
- уточнены граничные значения;
- удалены проверки, которые не следуют из MVP-описания;
- отдельно зафиксированы граничные вопросы ктебованиям.
