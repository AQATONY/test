# Граничные условия и критичные кейсы

## Город отправления и город назначения

| ID | Priority | Значение/сценарий | Ожидаемый результат | Почему критично |
|---|---|---|---|---|
| BC-CITY-01 | High | Пустой город отправления | Расчет недоступен, ошибка у поля | Без города нельзя построить маршрут |
| BC-CITY-02 | High | Пустой город назначения | Расчет недоступен, ошибка у поля | Без города нельзя построить маршрут |
| BC-CITY-03 | High | Ручной ввод без выбора из списка | Значение не считается валидным, если API ожидает city_id | Иначе API получит текст вместо ID |
| BC-CITY-04 | High | Город удален из базы после выбора | При расчете показывается ошибка актуальности справочника | Защита от stale reference |
| BC-CITY-05 | High | Отправление и назначение одинаковые | Запрет или отдельное бизнес-подтверждение | Маршрут может быть бессмысленным или тарифицироваться отдельно |
| BC-CITY-06 | Medium | Ввод с пробелами в начале/конце | Пробелы нормализуются, поиск работает | Частый UX-дефект автокомплита |
| BC-CITY-07 | Medium | Город с `ё`, дефисом, пробелом | Город корректно находится и выбирается | Российские города часто содержат такие символы |
| BC-CITY-08 | Medium | Нет подсказок по запросу | Показан empty state "город не найден" | Пользователь понимает причину |

## Вес груза

Предположение: максимум 20 000 кг включительно, пока требования не уточнят обратное.

| ID | Priority | Значение | Ожидаемый результат | Почему критично |
|---|---|---|---|---|
| BC-W-01 | Critical | пусто | Ошибка обязательного поля | Без веса нельзя рассчитать тариф |
| BC-W-02 | Critical | `0` | Ошибка | Нулевой груз не должен считаться перевозкой |
| BC-W-03 | High | `0.001` | Принять или отклонить по согласованной точности | Нужно определить минимальный допустимый вес |
| BC-W-04 | High | `1` | Принимается | Минимальный нормальный кейс |
| BC-W-05 | Critical | `20000` | Принимается | Проверка включительности максимума |
| BC-W-06 | Critical | `20000.001` | Ошибка превышения | Защита от выхода за лимит MVP |
| BC-W-07 | High | `-1` | Ошибка | Негативные значения недопустимы |
| BC-W-08 | Medium | `20 000`, `20000,5`, `020000` | Поведение определено и одинаково на fronted/backend | Локализация чисел и ввод пользователем |
| BC-W-09 | Medium | `1e3` | Отклонить или нормализовать явно | Scientific notation часто проходит в HTML number |
