# Чек-лист основного бизнес-процесса ЭТрН

## Smoke path

| ID | Priority | Проверка | Ожидаемый результат |
|---|---|---|---|
| ETRN-SM-01 | Critical | Грузоотправитель создает новую ЭТрН | Создан документ в статусе черновика, присвоен внутренний ID |
| ETRN-SM-02 | Critical | Грузоотправитель заполняет обязательные поля первого титула | Форма принимает валидные данные, ошибки отсутствуют |
| ETRN-SM-03 | Critical | Грузоотправитель сохраняет черновик | Данные сохраняются и восстанавливаются после reload/logout/login |
| ETRN-SM-04 | Critical | Грузоотправитель подписывает и отправляет первый титул | Подпись проходит, титул отправлен оператору ЭДО, статус меняется только после успешной отправки |
| ETRN-SM-05 | Critical | Перевозчик получает первый титул | Титул доступен перевозчику, содержит УИД/номер/реквизиты исходной ЭТрН |
| ETRN-SM-06 | Critical | Перевозчик подтверждает получение и отправляет следующий титул без замечаний | Статус у грузоотправителя меняется на "Груз принят к перевозке" или согласованный аналог |
| ETRN-SM-07 | High | Водитель получает QR-код | QR-код валиден, связан с конкретной ЭТрН и недоступен посторонним |
| ETRN-SM-08 | Critical | Грузополучатель принимает груз без замечаний | Финальный статус отражает прием груза грузополучателем |

## Создание и черновик

| ID | Priority | Проверка | Ожидаемый результат |
|---|---|---|---|
| ETRN-CR-01 | High | Открыть форму создания под ролью грузоотправителя | Доступ разрешен только роли с правом создания |
| ETRN-CR-02 | High | Открыть форму создания под ролью перевозчика/водителя/грузополучателя | Создание недоступно, отображается корректный отказ доступа |
| ETRN-CR-03 | High | Сохранить черновик с частично заполненными необязательными полями | Черновик сохраняется, обязательность отправки не применяется до отправки |
| ETRN-CR-04 | Critical | Попытаться отправить черновик без обязательных полей | Отправка заблокирована, ошибки подсвечены у полей |
| ETRN-CR-05 | Medium | Открыть черновик в двух вкладках и изменить одно поле | Система предотвращает потерю изменений или показывает конфликт версии |

## Подпись и отправка

| ID | Priority | Проверка | Ожидаемый результат |
|---|---|---|---|
| ETRN-SIGN-01 | Critical | Подписать титул валидным сертификатом владельца роли | Документ подписан, сохраняется информация о подписанте |
| ETRN-SIGN-02 | Critical | Подписать титул сертификатом другой организации | Подписание отклонено |
| ETRN-SIGN-03 | Critical | Подписать титул истекшим или отозванным сертификатом | Подписание отклонено, статус не меняется |
| ETRN-SIGN-04 | High | Нажать отправку дважды во время обработки | Создается один внешний message, повторный клик заблокирован или идемпотентен |
| ETRN-SIGN-05 | High | ЭДО недоступен во время отправки | Документ остается в состоянии ошибки/ожидания повтора, не показывается ложный успех |

## Статусы и маршрутизация

| ID | Priority | Проверка | Ожидаемый результат |
|---|---|---|---|
| ETRN-ST-01 | Critical | Получить первый титул перевозчиком | Статус доступен перевозчику, грузоотправитель видит ожидаемое состояние |
| ETRN-ST-02 | Critical | Попытаться перевести ЭТрН в "Груз принят к перевозке" без титула перевозчика | Переход заблокирован |
| ETRN-ST-03 | High | Получить дубль сообщения от ЭДО | Дубль не создает второй титул и не меняет статус повторно |
| ETRN-ST-04 | High | Получить сообщение по неизвестному УИД ЭТрН | Событие уходит в error queue/manual review, пользовательский документ не меняется |
| ETRN-ST-05 | High | Получить событие следующего титула раньше предыдущего | Событие не применяется до восстановления последовательности |

## Замечания при погрузке

| ID | Priority | Проверка | Ожидаемый результат |
|---|---|---|---|
| ETRN-LOAD-01 | High | Перевозчик отвечает "замечаний нет" | Поля замечаний не обязательны, процесс продолжается |
| ETRN-LOAD-02 | Critical | Перевозчик отмечает "есть замечания" и не заполняет поля несоответствия | Подписание заблокировано |
| ETRN-LOAD-03 | High | Перевозчик заполняет замечания по массе/местам/погрузке | Замечания сохраняются, попадают в титул и видны нужнын ролям |
| ETRN-LOAD-04 | High | Попытаться изменить замечания после подписания | Изменение запрещено без сценария исправления |

## QR-код и водитель

| ID | Priority | Проверка | Ожидаемый результат |
|---|---|---|---|
| ETRN-QR-01 | High | Сгенерировать QR-код после подтверждения перевозчиком | QR содержит только безопасный идентификатор, не раскрывает лишние персональные/коммерческие данные |
| ETRN-QR-02 | High | Открыть QR-код водителем, не связанным с перевозкой | Доступ запрещен |
| ETRN-QR-03 | Medium | Открыть QR-код после истечения срока действия | Показывается ошибка и сценарий получения нового QR |
| ETRN-QR-04 | High | Водитель отмечает прибытие на погрузку/разгрузку | Время и событие фиксируются в истории процесса |

## Прием груза грузополучателем

| ID | Priority | Проверка | Ожидаемый результат |
|---|---|---|---|
| ETRN-REC-01 | Critical | Грузополучатель принимает груз без замечаний | ЭТрН получает финальный успешный статус |
| ETRN-REC-02 | High | Грузополучатель фиксирует замечания при выгрузке | Замечания обязательны для заполнения и включаются в титул |
| ETRN-REC-03 | Critical | Грузополучатель отказывается от груза | Процесс уходит в ветку отказа, статус не равен успешному принятию |
| ETRN-REC-04 | High | Грузополучатель пытается принять груз до прибытия водителя | Действие недоступно или требует отдельного подтвержденного события |

## Аудит и история

| ID | Priority | Проверка | Ожидаемый результат |
|---|---|---|---|
| ETRN-AUD-01 | High | Открыть историю документа | Видны статусы, участники, время, результат отправок и ID внешних сообщений |
| ETRN-AUD-02 | High | Проверить историю после ошибки отправки | Ошибка сохранена без секретов и технических стек-трейсов для пользователя |
| ETRN-AUD-03 | Medium | Экспорт/печать формы ЭТрН | Реквизиты соответствуют утвержденной форме, лишние служебные поля не выводятся |
