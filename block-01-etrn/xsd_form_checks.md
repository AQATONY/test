# Проверки формы и XSD

## Уровень файла обмена

| ID | Priority | Проверка | Ожидаемый результат |
|---|---|---|---|
| XSD-FILE-01 | Critical | Имя файла первого титула соответствует шаблону `ON_TRNVPRGO_...xml` | Имя файла валидно, расширение `xml` допустимо в любом регистре |
| XSD-FILE-02 | High | XML начинается с `<?xml version="1.0" encoding="windows-1251"?>` | Кодировка и декларация соответствуют формату |
| XSD-FILE-03 | Critical | `ИдФайл` повторяет имя файла без расширения | Несовпадение блокирует отправку |
| XSD-FILE-04 | Critical | `ВерсФорм` равен `5.01` | Иная версия блокируется или обрабатывается по миграционным правилам |
| XSD-FILE-05 | High | Если в имени файла признак W равен `1`, заполнены `ИдПолИной` | При W=1 отсутствие дополнительных получателей считается ошибкой |

## Документ и первый титул грузоотправителя

| ID | Priority | Поле/элемент | Проверка | Ожидаемый результат |
|---|---|---|---|---|
| XSD-GO-01 | Critical | `КНД` | Значение равно `1110430`, длина 7 цифр | Иное значение отклоняется |
| XSD-GO-02 | Critical | `НаимТрН` | Допустимы только значения 1, 2, 3 | Иное значение отклоняется |
| XSD-GO-03 | Critical | `ДатаИнфГО`, `ДатаТрН`, `ДатаПогруз` | Формат `ДД.ММ.ГГГГ`, дата существует в календаре | `31.02.2026` и неверный формат отклоняются |
| XSD-GO-04 | High | `ВрИнфГО` | Формат `ЧЧ:ММ:СС`, диапазон 00:00:00 - 23:59:59 | `24:00:00` отклоняется |
| XSD-GO-05 | Critical | `НомерТрН` | Обязателен, длина 1-1000 | Пустой номер блокирует отправку |
| XSD-GO-06 | Critical | `ПортОтпр`, `ПортНазнач` | Обязательны наименование порта и адрес | Отсутствие адреса блокирует отправку |
| XSD-GO-07 | Critical | `СвГО`, `СвГП`, `СвПрв` | Обязательны идентификационные сведения и адрес | Нельзя отправить без одной из сторон |
| XSD-GO-08 | Critical | ИНН/КПП | ИНН ЮЛ 10 цифр, ИНН ФЛ/ИП 12 цифр, КПП 9 символов по шаблону | Неверная длина/символы отклоняются |
| XSD-GO-09 | Critical | `СвГруз` | Блок сведений о грузе обязателен | Нельзя отправить пустой груз |
| XSD-GO-10 | Critical | `ВыгрузСредств` | Значение только `1` или `2` | Иное значение отклоняется |
| XSD-GO-11 | Critical | `ОпГруз` | Минимум один блок описания груза | Нельзя отправить без описания |
| XSD-GO-12 | Critical | `СостГруз`, `СпУпак`, `НаимГруз`, `ВесГруз` | Обязательные поля груза заполнены | Пустые значения блокируют отправку |
| XSD-GO-13 | High | `ВесГруз` | Число `N(18.4)`, положительное, кг | Ноль, отрицательное и больше разрешенной точности отклоняются |
| XSD-GO-14 | Medium | `КолМестГр` | Для насыпных/наливных грузов допускается значение `1` | Бизнес-правило проверяется отдельно от XSD |
| XSD-GO-15 | High | `Марк` | Если маркировки нет, значение должно быть `Отсутствует` | Пустой повторяемый элемент не создается |
| XSD-GO-16 | Critical | `СопрДок` | Минимум один сопроводительный документ, если он обязателен по бизнес-типу груза | Отсутствие документа блокирует сценарий, где документ обязателен |
| XSD-GO-17 | Critical | `ПодпИнфГО` | Сведения подписанта обязательны | Нельзя подписать без подписанта |

## Титул перевозчика

| ID | Priority | Поле/элемент | Проверка | Ожидаемый результат |
|---|---|---|---|---|
| XSD-PRV-01 | Critical | `ИдФайлИнфГО`, `ДатФайлИнфГО`, `ВрФайлИнфГО`, `ЭП` | Титул перевозчика ссылается на файл грузоотправителя и его подпись | Невозможно создать титул перевозчика без первого титула |
| XSD-PRV-02 | Critical | `СвСудно`, `НазвСудно` | Сведения о судне обязательны для титула перевозчика | Отсутствие судна блокирует подпись |
| XSD-PRV-03 | High | `ЗамПрвПрием`, `ЗамСостГруз` | При наличии замечаний заполнены дата/время и обстоятельства | Пустые замечания не подписываются |
| XSD-PRV-04 | High | `ОтметПрвПрием` | Отметки перевозчика не теряются при отправке | Следующий участник видит отметки |

## Титул грузополучателя и выдача груза

| ID | Priority | Поле/элемент | Проверка | Ожидаемый результат |
|---|---|---|---|---|
| XSD-GP-01 | Critical | `ИдФайлПрв`, `ДатФайлПрв`, `ВрФайлПрв`, `ЭП` | Титул грузополучателя связан с титулом перевозчика | Невозможно принять груз без предыдущего титула |
| XSD-GP-02 | Critical | `ПриемГрузГП` | Прием груза фиксируется с фактическими характеристиками | Финальный статус не ставится без приема или отказа |
| XSD-GP-03 | High | `АдрВыгруз` | Адрес выгрузки обязателен | Пустой адрес блокирует подписание |
| XSD-GP-04 | High | `ФДатВрПриб`, `ФДатВрУбыт`, `ЗаявДатВрПриб` | Формат даты-времени с часовым поясом | Неверный формат отклоняется |
| XSD-GP-05 | High | `СвПринГруз`, `МасГруз`, `КолМест` | Фактические сведения о принятом грузе не противоречат замечаниям | Несоответствия требуют замечаний или отдельного статуса |

## Интеграционные проверки XSD

1. Сгенерировать XML по каждому титулу и прогнать XSD-валидацию до отправки.
2. Проверить, что UI-валидация не слабее XSD: пользователь не должен узнавать о базовой ошибке только после отправки.
3. Проверить, что сервер повторно валидирует XML независимо от frontend.
4. Проверить совместимость чтения документов старых XSD-версий и запрет отправки устаревшей версии, если это требуется бизнесом.
5. Проверить, что технические ошибки XSD показываются пользователю понятным текстом: поле, причина, действие.
