4. Подробные баг-репорты

QA-01 · Форма показывает успех после API 500High
Окружение
Staging, Chrome 128, desktop 1440×900
Предусловие
Endpoint /api/leads возвращает HTTP 500.
Шаги
  1. Открыть страницу заявки.
  2. Заполнить валидными данными.
  3. Отправить форму.
Фактический результат
Показывается сообщение «Заявка отправлена», форма очищается. В Network — HTTP 500.
Ожидаемый результат
Показать ошибку и сохранить данные для повторной отправки.
Бизнес-риск
Пользователь уверен, что заявка получена, однако лид отсутствует в системе.
Доказательства
Видео, HAR и response body прикладываются к задаче.
QA-02 · CTA перекрывает поле формы на mobileMedium
Окружение
Chrome responsive mode, viewport 390×844.
Фактический результат
Sticky CTA перекрывает нижнюю часть поля и подсказку валидации.
Ожидаемый результат
Все поля и сообщения доступны без перекрытия.
Рекомендация
Учесть высоту sticky-элемента в нижнем padding контейнера.
QA-03 · Профиль остаётся видимым после выходаHigh
Шаги
  1. Авторизоваться.
  2. Открыть профиль.
  3. Нажать «Выйти».
  4. Вернуться назад кнопкой браузера.
Фактический результат
Данные профиля отображаются до принудительного обновления.
Ожидаемый результат
Защищённый экран не доступен после завершения сессии.
